The script will:
1. Run 5 consecutive mining rounds on Base network
2. Check balance and time remaining before each deploy
3. Deploy to blocks if conditions are met
4. Output deploy statistics and pending rewards

This requires blockchain credentials (`AGENT_PRIVATE_KEY`, `BASE_RPC_URL`, `AGENT_ADDRESS`) to be set as environment variables. Once you approve, I'll execute it and then auto-claim any pending rewards based on configured thresholds.
